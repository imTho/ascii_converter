# Image to ASCII Art Converter

This web application allows users to convert images into ASCII art. Users can upload an image, and the app will process it to generate an ASCII representation. Additionally, users can customize the ASCII text color and background color.
(Raw JS, no packages needed)

## Features

- Upload an image file to convert to ASCII art
- Customize ASCII text color
- Customize background color
- Responsive design with monospace font for better ASCII art display

## Usage

1. Open the `index.html` file in a web browser.
2. Click on the "Choose File" button to upload an image.
3. Adjust the ASCII text color and background color using the color pickers.
4. View the generated ASCII art in the textarea.
